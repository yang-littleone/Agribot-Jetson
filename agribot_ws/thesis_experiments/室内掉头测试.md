# 室内掉头测试（三窗口）

这个试验不启动真实玉米行检测器。模拟节点根据真实 `/odometry/filtered` 发布：第一条 1 m 中心线、地头信号、与第一条平行且方向相反的第二条 1 m 中心线。实际掉头仍由冻结版 PID 控制器完成。

开始前清空场地，安全员持物理急停。左转时第二条线位于第一条线左侧，右转时位于右侧。按 0.60 m 行距计算，建议至少准备约 3 m × 2 m 的无障碍区域，并额外计入车体外廓。第一次先架空检查话题和车轮方向，再落地测试。

## 窗口一：只启动底盘和定位

```bash
cd /home/wheeltec/agribot/agribot_ws
source install/setup.bash

ros2 launch turn_on_agribot turn_on_agribot.launch.py \
  use_rviz:=false
```

确认定位正常：

```bash
ros2 topic echo /odometry/filtered --once
```

不要运行 `field_system_with_perception.launch.py`，否则真实检测器会与模拟器发布同名中心线。

## 窗口二：录包

```bash
cd /home/wheeltec/agribot/agribot_ws
source install/setup.bash

ros2 run centerline_extraction record_field_bag.sh \
  indoor_turn_left_r1
```

看到 `Recording` 后再启动窗口三。

## 窗口三：模拟两条作物行并执行掉头

```bash
cd /home/wheeltec/agribot/agribot_ws
source install/setup.bash

ros2 launch thesis_field_experiments indoor_headland_test.launch.py \
  trial_id:=indoor_turn_left_r1 \
  scenario:=indoor_synthetic_headland \
  repeat_index:=1 \
  max_linear_speed:=0.12 \
  headland_turn_linear_speed:=0.10 \
  target_distance:=0.20 \
  headland_turn_target_distance:=0.20 \
  headland_min_follow_distance:=0.80 \
  headland_row_spacing:=0.60 \
  headland_turn_radius:=0.0 \
  headland_exit_distance:=0.15 \
  headland_settle_distance:=0.60 \
  headland_turn_goal_tolerance:=0.10 \
  headland_turn_heading_tolerance:=0.35 \
  headland_use_continuous_curvature_turn:=false \
  headland_turn_direction:=left \
  first_line_length:=1.00 \
  second_line_length:=1.00 \
  start_delay:=5.0 \
  max_time:=120.0
```

其中，`headland_turn_radius:=0.0` 表示自动使用行距的一半，即 0.60 m
行距对应 0.30 m 半径。`headland_exit_distance` 是检测到地头后、进入圆弧前继续
直行的距离。`headland_turn_goal_tolerance:=0.10` 将掉头终点的位置容差收紧到
10 cm；如果车辆在终点附近反复调整而不能进入第二行，可改回 `0.15` 或 `0.20`。

不常调整的重捕获参数也已经开放，可用下面的命令查看全部参数及默认值：

```bash
ros2 launch thesis_field_experiments indoor_headland_test.launch.py --show-args
```

启动后车辆静止等待 5 秒，然后按以下状态运行：

```text
FIRST_ROW（第一条1 m直线）
→ HEADLAND（空中心线＋地头信号）
→ U_TURN（真实PID掉头）
→ SECOND_ROW（重捕获平行第二条线）
→ FINISHED（持续空路径，控制器保持停车）
```

终端出现 `FINISHED` 后，先确认车辆已经停止，再在窗口三按 `Ctrl+C`，最后在窗口二按 `Ctrl+C`。窗口一最后关闭。

运行中可观察：

```bash
ros2 topic echo /indoor_test_stage
ros2 topic echo /navigation_mode
ros2 topic echo /cmd_vel
```

右转只需同时更改试验编号和方向：

```text
trial_id:=indoor_turn_right_r1
headland_turn_direction:=right
```

若 `0.12 m/s` 无法克服底盘死区，可在确保场地和急停安全后小幅提高 `max_linear_speed`，但同一组正式重复试验必须锁定相同速度。
