# 大论文现场三窗口操作

操作方式与小论文一致：窗口一启动底盘和检测，窗口二录包，窗口三启动行走。每个窗口都先执行：

```bash
cd /home/wheeltec/agribot/agribot_ws
source install/setup.bash
```

## 窗口一：启动底盘和玉米行检测

```bash
ros2 launch centerline_extraction field_system_with_perception.launch.py \
  use_rviz:=false
```

等点云、里程计和中心线输出稳定后再继续。这个窗口在当天全部试验结束后才停止。

## 窗口二：记录本次试验

试验编号必须与窗口三完全相同：

```bash
ros2 run centerline_extraction record_field_bag.sh \
  turn_left_commissioning_r1
```

看到“Recording”后再启动窗口三。

## 窗口三：第一次低速左掉头

先测量现场相邻两行的平均中心距。下面以 `0.60 m` 为例：

```bash
ros2 launch thesis_field_experiments headland_path_tracking.launch.py \
  quality_aware:=true \
  max_distance:=0.0 \
  max_time:=60.0 \
  enable_headland_turn:=true \
  max_headland_turns:=1 \
  headland_min_follow_distance:=1.50 \
  headland_turn_radius:=0.0 \
  headland_exit_distance:=0.25 \
  headland_settle_distance:=0.60 \
  headland_path_step:=0.05 \
  headland_use_continuous_curvature_turn:=false \
  headland_turn_goal_tolerance:=0.10 \
  headland_turn_heading_tolerance:=0.35 \
  headland_reacquire_search_speed:=0.08 \
  trial_id:=F_TL_P01_R01 \
  scenario:=formal_turn \
  repeat_index:=1 \
  headland_turn_direction:=left \
  headland_row_spacing:=0.60 \
  max_linear_speed:=0.18 \
  headland_turn_linear_speed:=0.10 \
  target_distance:=0.20 \
  headland_turn_target_distance:=0.10
```

这次只验证一次低速左掉头。`headland_row_spacing` 必须换成现场实测平均行距；
`headland_turn_radius:=0.0` 表示按行距一半自动计算半径；
`headland_exit_distance` 是检测到地头后继续向前的规划距离；
`target_distance` 用于正常行间跟踪，`headland_turn_target_distance` 只用于掉头。
若地头前方空间不足以容纳车体和 0.25 m 前进段，必须先降低
`headland_exit_distance`，不能直接照搬室内值。
命令最后九项是现场最常修改的参数，已集中放在末尾。

查看实地 launch 已开放的全部参数：

```bash
ros2 launch thesis_field_experiments headland_path_tracking.launch.py --show-args
```

## 正确的停止顺序

1. 先在窗口三按 `Ctrl+C`，确认机器人停止、`/cmd_vel` 不再输出运动命令。
2. 再在窗口二按 `Ctrl+C`，让 rosbag 写完元数据并自动验收。
3. 窗口一保持运行，下一次试验可以继续使用。
4. 危险情况下直接按物理急停，不等待软件停止。

## 后续试验只改哪些参数

右掉头：

```text
trial_id:=turn_right_r1
scenario:=turn_right
headland_turn_direction:=right
```

连续四次掉头：

```text
trial_id:=multirow_left_r1
scenario:=multirow
headland_turn_direction:=left
max_headland_turns:=4
```

只测试地头检测、不自动掉头：

```text
trial_id:=headland_detection_positive_r1
scenario:=headland_positive
enable_headland_turn:=false
```

完成低速调试后，正式速度组才改为：

```text
max_linear_speed:=0.18
headland_turn_linear_speed:=0.15
headland_reacquire_search_speed:=0.15
```

其余参数保持不变。每次试验使用新的 `trial_id`，失败试验也不得覆盖或删除。
