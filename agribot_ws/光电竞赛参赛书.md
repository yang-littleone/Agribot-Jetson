# AgriBot智能农业自主导航系统
## 光电设计竞赛创意组参赛书

---

### 摘要

本项目设计并实现了一套基于ROS2框架的智能农业自主导航系统——AgriBot。系统采用3D点云传感技术，结合PCL点云处理算法和Pure Pursuit纯追踪控制策略，实现了作物行自动检测、中线提取和精准路径跟踪功能。通过多传感器融合定位技术和STM32底盘控制系统，系统在复杂农田环境中展现出良好的导航精度和稳定性。本作品深度融合光电传感、信号处理、自动控制等专业知识，为智慧农业提供了低成本、高精度的自动化解决方案。

**关键词**：智能农业；ROS2；点云处理；Pure Pursuit算法；自主导航；光电传感

### 4.2 关键技术详解

#### 4.2.1 点云预处理与作物行检测

**技术流程**：

1. **点云采集**
   - 3D激光雷达以10Hz频率扫描周围环境
   - 原始点云包含x,y,z三维坐标及反射强度信息
   - 典型数据量：每帧约30,000个点

2. **ROI区域裁剪**
   ```cpp
   // 高度过滤：只保留地面以上0-0.5米的点（作物茎秆区域）
   z_min = 0.0m, z_max = 0.5m
   
   // 前后范围：车前0.5-5米（避免过近盲区）
   x_min = 0.5m, x_max = 5.0m
   
   // 左右范围：车两侧各2米
   y_min = -2.0m, y_max = 2.0m
   ```

3. **体素下采样**
   - 体素大小：2cm × 2cm × 2cm
   - 作用：降低数据量，提高处理速度
   - 效果：点数减少80%，保留几何特征

4. **XY平面投影**
   - 将3D点云投影到2D平面
   - 忽略高度信息，聚焦横向分布
   - 形成"鸟瞰图"视角

5. **左右行分割**
   - 以机器人中心线（y=0）为界
   - 左侧点云：y < 0
   - 右侧点云：y > 0
   - 分别处理，提高鲁棒性

6. **最内侧行提取**（多行场景）
   - **方法1：固定阈值聚类**
     - 横向间距阈值：0.2m
     - DBSCAN聚类算法
     - 选择距离中心最近的簇
   
   - **方法2：自适应阈值**（创新点）
     ```cpp
     // 计算相邻点列间距的中位数
     median_gap = median(gaps)
     
     // 分割阈值 = 中位数 × 放大因子
     threshold = median_gap × gap_multiplier
     
     // 优势：适应不同行距的作物
     ```

7. **直线拟合**
   - RANSAC随机采样一致性算法
   - 模型：y = kx + b
   - 输出：斜率k、截距b
   - 抗噪性强，可剔除离群点

#### 4.2.2 路径平滑与时空滤波

**问题**：原始拟合的路径存在抖动，直接跟踪会导致车辆震荡

**解决方案**：三级平滑策略

1. **异常值剔除**
   ```cpp
   // 计算路径点斜率变化
   for each point i:
       slope_change = |slope[i] - slope[i-1]|
       
       if slope_change > outlier_threshold:
           标记为异常点，用邻近点插值替换
   ```

2. **空间平滑**（加权移动平均）
   ```cpp
   smoothed_point[i] = weight × point[i] + 
                      (1-weight)/2 × (point[i-1] + point[i+1])
   
   // 推荐权重：0.7（保持原路径70%特征）
   ```

3. **时间平滑**（历史路径融合）
   ```cpp
   // 维护一个长度为5的历史路径队列
   path_history.push_back(current_path)
   
   if path_history.size() > 5:
       path_history.pop_front()
   
   // 对队列中所有路径求平均
   final_path = average(path_history)
   ```

**效果**：路径抖动减少90%，跟踪平稳性显著提升

#### 4.2.3 Pure Pursuit路径跟踪算法

**算法原理**：

Pure Pursuit是一种几何路径跟踪方法，核心思想是寻找路径上距离当前位置固定前视距离的目标点，计算机器人到该点的圆弧曲率，从而生成角速度控制指令。

**数学推导**：

设机器人在全局坐标系下的位置为$(x_r, y_r)$，航向角为$\theta_r$。前视点在全局坐标系下的位置为$(x_l, y_l)$。

1. **坐标变换**：将前视点转换到机器人坐标系
   $$
   \begin{bmatrix} x_{local} \\ y_{local} \end{bmatrix} = 
   \begin{bmatrix} \cos\theta_r & \sin\theta_r \\ -\sin\theta_r & \cos\theta_r \end{bmatrix}
   \begin{bmatrix} x_l - x_r \\ y_l - y_r \end{bmatrix}
   $$

2. **曲率计算**：圆弧曲率$\kappa$
   $$
   \kappa = \frac{2y_{local}}{L^2}
   $$
   其中$L$为前视距离（lookahead distance）

3. **角速度生成**：
   $$
   \omega = v \cdot \kappa = \frac{2v \cdot y_{local}}{L^2}
   $$
   其中$v$为线速度

**自适应前视距离**（创新改进）：

传统Pure Pursuit使用固定前视距离，难以兼顾高速稳定性和低速灵活性。本作品提出自适应机制：

$$
L = L_{base} \cdot (1 + k_v \cdot v)
$$

其中：
- $L_{base}$：基础前视距离（0.5m）
- $k_v$：速度增益系数（0.5）
- $v$：当前线速度

**优势**：
- 低速时（v=0.2m/s）：L≈0.55m，响应灵敏
- 高速时（v=0.5m/s）：L≈0.625m，运行平稳

**速度自适应调节**：

根据横向误差动态调整线速度：
$$
v = v_{max} - K_e \cdot |e_y|
$$

其中：
- $v_{max}$：最大允许速度（0.5m/s）
- $K_e$：误差增益（0.5）
- $e_y$：横向误差

**效果**：误差大时自动降速，提高安全性

#### 4.2.4 多传感器融合定位

**传感器配置**：

| 传感器 | 频率 | 提供信息 | 精度 |
|-------|------|---------|------|
| 轮式编码器 | 50Hz | 位移、速度 | ±3% |
| IMU陀螺仪 | 100Hz | 角速度、加速度 | 0.01°/s |
| IMU加速度计 | 100Hz | 线性加速度 | 0.001g |

**EKF扩展卡尔曼滤波**：

1. **状态向量**：
   $$
   \mathbf{x} = [x, y, \theta, v_x, v_y, \omega]^T
   $$

2. **预测阶段**（基于运动学模型）：
   $$
   \mathbf{x}_{k|k-1} = f(\mathbf{x}_{k-1}, \mathbf{u}_k)
   $$
   $$
   \mathbf{P}_{k|k-1} = \mathbf{F}_k \mathbf{P}_{k-1} \mathbf{F}_k^T + \mathbf{Q}_k
   $$

3. **更新阶段**（融合IMU观测）：
   $$
   \mathbf{K}_k = \mathbf{P}_{k|k-1} \mathbf{H}_k^T (\mathbf{H}_k \mathbf{P}_{k|k-1} \mathbf{H}_k^T + \mathbf{R}_k)^{-1}
   $$
   $$
   \mathbf{x}_k = \mathbf{x}_{k|k-1} + \mathbf{K}_k (\mathbf{z}_k - h(\mathbf{x}_{k|k-1}))
   $$
   $$
   \mathbf{P}_k = (\mathbf{I} - \mathbf{K}_k \mathbf{H}_k) \mathbf{P}_{k|k-1}
   $$

**协方差矩阵调优**：

```cpp
// 里程计位置协方差（较小，信任度高）

                        0, 1e-3, 0, 0, 0, 0,
                        ...}

                         0, 1e-3, 1e-9, 0, 0, 0,
                         ...}
```

**效果**：定位精度提升至±2cm，航向角误差<0.5°

## 八、参赛作品与光电专业的相关度

### 8.1 光电技术应用

#### 8.1.1 激光雷达技术（核心光电传感器）

**工作原理**：
- 采用TOF（Time of Flight）飞行时间法测距
- 发射激光脉冲，测量往返时间
- 计算公式：$d = \frac{c \cdot t}{2}$
  - $c$：光速（3×10⁸ m/s）
  - $t$：往返时间

**关键技术**：
1. **激光发射模块**
   - 波长：905nm（近红外，人眼安全）
   - 功率：<1mW（Class 1激光产品）
   - 发散角：0.2°

2. **接收模块**
   - APD雪崩光电二极管
   - 灵敏度：-40dBm
   - 响应时间：<5ns

3. **扫描机构**
   - 旋转棱镜或多面镜
   - 转速：10Hz（每秒10圈）
   - 角分辨率：0.2°

**在本作品中的应用**：
- 3D环境感知
- 作物行几何特征提取
- 障碍物检测与避障

#### 8.1.2 光电编码技术

**增量式编码器**：
- 安装在电机输出轴
- 光栅盘：500线/圈
- A/B相正交输出，判断方向
- Z相零位信号

**测速原理**：
$$
v = \frac{N \cdot \pi \cdot D}{P \cdot \Delta t}
$$
- $N$：脉冲数
- $D$：轮径
- $P$：编码器线数
- $\Delta t$：采样时间

**精度**：±1%

#### 8.1.3 光纤通信（预留接口）

- 未来可扩展光纤以太网
- 优势：抗电磁干扰、长距离传输
- 适用：大型农场多机协同

### 8.2 光学算法

#### 8.2.1 点云配准算法

**ICP（Iterative Closest Point）迭代最近点**：
- 用于多帧点云拼接
- 最小化点对距离平方和
- 收敛条件：误差<1mm或迭代>50次

#### 8.2.2 光束法平差

- 优化激光雷达外参标定
- 最小化重投影误差
- 提升多传感器一致性

- **镀膜**：增透膜（905nm波段反射率<0.5%）
